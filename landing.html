API for developers & agents — pay per search, no signup

Built for AI agents as much as for people. No account, no API key — pay $0.02 in USDC on Base per search via x402. Your client pays, the search runs, you get JSON back.

GET /api/v1/search?q=deep+learning&cat=academic

An unpaid request returns 402 Payment Required with payment terms in the PAYMENT-REQUIRED header. Sign the payment (EIP-3009 USDC) and retry with an X-PAYMENT header — a standard x402 client handles this for you. Works with any x402 client library. Full spec: /openapi.json.

Questions

Is my search history private?

Yes. We don't log your queries, don't sell data, and don't show ads. Usage counts (how many searches today) are tracked only to enforce the free-tier limit.

Why 186 engines?

Mainstream search engines show you the same popular results. The independent web — small sites, archives, niche communities, academic repositories — is invisible to Google. DeepSearch checks all of it.

What about the adult engines?

The adult category (166 engines) is available on Pro and API plans only, for users 18 and older. It's the most comprehensive adult meta-search available anywhere — every major tube plus niche, regional, and amateur sites in one query.

Can I cancel?

Anytime. Your plan stays active until the end of the current billing period, then drops to Free.
